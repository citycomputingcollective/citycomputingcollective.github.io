# Contributing to City Computing Collective

You can contribute by:

- Welcoming new members and answering questions.
- Posting a well-scoped collaboration request.
- Sharing a documented dataset, tool, benchmark, or city case.
- Proposing or maintaining a community project.
- Organizing a reading group, methods clinic, demo, or local meetup.
- Improving the website, templates, documentation, or accessibility.
- Helping moderate and organize content.

Before contributing code or content, read the Code of Conduct. Do not submit confidential, private, copyrighted, or restricted material without permission.
